# OCR Practice & Testing

This branch contains experiments with **image preprocessing** and **OCR techniques** for Pokémon trading cards.

## Methods Explored
- Autocropping card borders
- Contour detection
- Noise reduction and thresholding
- OCR testing (extracting card names from cropped regions)

## Contents
- Jupyter notebooks testing different preprocessing pipelines
- Sample images and experiments with OpenCV

## Status
Work-in-progress experiments to improve OCR accuracy before integrating into the full pipeline.
